# Gardenia 个人网站 · 产品需求文档（PRD）

| 项目 | 内容 |
| --- | --- |
| 产品名 | Gardenia（栀子小屋） |
| 形态 | 单页个人主页，纯静态 |
| 技术栈 | Astro 7 + React 岛 + TypeScript，pnpm 管理 |
| 目标环境 | 桌面与移动浏览器，先本地预览 |
| 文档版本 | v1.3 |

---

## 1. 项目概述

### 1.1 一句话定位

一个让人想早点回家的个人主页：推开门，暖灯亮着，桌上有甜的。

### 1.2 为什么要做

常见的个人主页像一张简历或一块公告板，信息齐全但没有温度。这个站点反过来——先给情绪，再给信息：访客在 3 秒内感到「暖」，然后才慢慢认识站主。它同时是给朋友的名片、给自己的一个小房间。

### 1.3 目标

- **主要目标**：访客打开首页的瞬间，感受到橙红暗光、木纹、夜风和「有人等你回来」的安定感。
- **次要目标**：访客能在一屏之内知道「这是谁、在哪能找到他」。
- **非目标**（本期明确不做）：博客系统、相册管理、作品集、留言板、后台、账号体系、多语言。

### 1.4 成功标准

1. 首页首屏无需滚动即可看到署名、一句话与暖光场景。
2. 所有文案读起来像「人在说话」，不出现「致力于」「专注于」这类简历腔。
3. `pnpm build` 零报错，产出纯静态文件；桌面 1440×900 与手机 390×844 下无横向滚动、无遮挡。
4. 关闭 JavaScript 后，文字、照片、链接仍然完整可读（动效降级，内容不丢）。

## 2. 设计概念与情绪板

### 2.1 场景叙事

把页面结构对应成「回家」的三段路，而不是三个功能模块：

```
傍晚的街 → 木栈道与路灯 → 门廊（首屏）→ 客厅（关于我）→ 玄关（页脚/联系）
```

- **傍晚的街**：深青的夜、雾、远处零星的窗灯。负责「外面有点凉」。
- **木栈道与路灯**：钠灯把木板照成橘金色，长长的影子。负责「走回来的那段路」。
- **门廊**：一盏为你留的灯。负责「到家了」。
- **客厅**：歪掉的拍立得、便签、没收拾的毯子。负责「这里住着一个人」。
- **玄关**：换鞋、道晚安、留联系方式。负责「下次再来」。

### 2.2 参考图如何转译

| 素材 | 内容 | 在站点中的用途 |
| --- | --- | --- |
| `images/Image_1793947012253_801.jpg` | 夜间木栈道，钠灯橘光，深青夜空 | 首屏主视觉：木纹质感、橘光方向、深青底色、长影子的构图参考 |
| `images/Image_1793947014016_878.jpg` | 街灯、树影、自行车、失焦光斑 | 光晕与虚化的质感参考；可作为「窗外」小卡片图 |
| `images/Image_1793948470150_734.jpg` | 毛绒脑袋、白毯子、电视里的 Minecraft | 「关于我」的拍立得主图，人格化的关键素材 |

三张图都做统一暖调处理：轻微偏暖、降低饱和、压暗边缘，保证和页面底色是同一个夜晚。

### 2.3 情绪关键词

`归宿感` · `暖橙暗光` · `木头的温度` · `刚出炉` · `毛绒` · `安静的夜` · `不打扰`

### 2.4 设计原则

1. **光是主角，文字是第二层**。任何元素都不能比灯晕更抢眼。
2. **暗而不脏**。深青底 + 琥珀光，避免纯黑和浑浊的棕。
3. **动效是呼吸，不是表演**。幅度小、速度慢、可关闭。
4. **甜但不腻**。可爱只出现在细节（拍立得、便签、一句晚安），不做卡通堆砌。
5. **留白即呼吸**。每段之间给足夜色，不塞满。

## 3. 信息架构

### 3.1 站点结构

```
/                    单页
├─ #top   门廊（Hero）
├─ #about 客厅（关于我）
└─ #bye   玄关（联系与晚安）
```

只有一条路由。不做二级页面，但组件与目录预留扩展位，未来加 `/notes` 只需新增页面，不改现有结构。

### 3.2 顶部导航

- 固定在顶部，初始透明，滚动超过首屏后浮现一层半透明深青 + 模糊背板。
- 左侧小字 `Gardenia`，右侧三个低对比锚点：`关于` / `找得到我`。
- 移动端保留同样的三个锚点，不做汉堡菜单（只有一页，没必要）。
- 当前区块高亮为琥珀色小圆点，不做下划线。

## 4. 页面与交互规格

### 4.1 门廊 Hero（`#top`）

**内容槽位**

| 槽位 | 文案（可替换） | 说明 |
| --- | --- | --- |
| 眉标 | `Gardenia · 栀子` | 字距 0.3em，12px，琥珀 60% 透明 |
| 主标题 | `今晚也早点回家。` | 桌面 64–80px，移动 36–42px |
| 副标题 | `这里留着一盏灯，和一点甜的。` | 奶油色 70%，行高 1.8 |
| 滚动提示 | `往下走` + 一颗缓慢下落的光点 | 2.8 秒循环，`reduced-motion` 时静止 |

**视觉**

- 背景：`#100D0B` 暖黑，叠加三层柔光斑（琥珀 94vmin、橙红 72vmin、暗玫瑰 58vmin），以 26–32 秒的周期缓慢游动，全部只动 `transform`；右下为主光。
- 木栈道：把图 1 的木板区域裁成横向条带，作为底部 47% 高度的背景，用 `mask-image: linear-gradient(to top, black, transparent)` 向上渐隐，不遮文字。
- 星空：移动端 32 颗 / 桌面 48 颗 2px 星点，红 / 白 / 黄（约 72% / 13% / 15%）；位置在页面加载时用 `Math.random()` 随机撒满 0–100%（每次刷新都不同），以 `mix-blend-mode: screen` 叠在木栈道照片之上；1.5–3.5 秒闪烁（透明度 0.2 → 1、scale 1 → 1.3），随指针做约 18px 视差。
- 火星：canvas 绘制 30–60 颗上升的暖色光尘（暖橙 / 浅金 / 少量玫红），`lighter` 混合、单 rAF 驱动。
- 指针视差：光斑约 22px、照片约 8px、星点约 18px；无指针时用正弦缓慢漂移；触屏与 `reduced-motion` 关闭。
- 噪点：SVG feTurbulence 生成的颗粒层，透明度 0.045，`pointer-events: none`，覆盖全站（fixed）。
- 暗角：径向渐变把四角压暗约 25%，引导视线到标题与木栈道。
- 不设具象灯具与灯光开关：光源全部来自柔光斑、星点与木栈道反光。

### 4.2 客厅 关于我（`#about`）

**布局**：桌面 5:7 两栏（左图右文），间距 80–120px，最大内容宽 1080px。移动端单列。

**左栏：拍立得**

- 白色偏奶油纸框（`#F4E9D8`），内边距上 14px / 左右 14px / 下 52px，照片 4:3。
- 整张卡片 `rotate(-2.4deg)`，hover 时 `rotate(0.4deg) translateY(-6px)`，阴影从 24px 增至 36px，过渡 400ms。
- 照片下方手写体 caption：`有点乱，但是我的窝`。
- 胶带贴纸：左上角一小条半透明米色胶带，`rotate(-6deg)`，轻微阴影。
- 图片：默认使用图 3；用 `astro:assets` 输出 WebP，加载时先显示暖色占位底色，避免 CLS。

**右栏：自述**

- 小标题 `关于我`（24px，琥珀，字距 0.1em）。
- 正文 2–3 段，每段 2–4 行，16–17px，行高 1.95，奶油色 88%。
- 语气示例（实现时按真实信息替换）：
  - 「住在一个会下很久雨的城市，喜欢把房间的灯调得比需要的更暗一点。」
  - 「白天写代码，晚上打游戏；毛绒脑袋是最近的新爱好。」
  - 「对热的、甜的、带黄油味的东西没有抵抗力。」
- 结尾手写签名 `— Gardenia`，使用标题字体斜置，右侧一小枚圆形印章（`G`，暗橘描边）。
- 便签区：三张小卡片横排，移动端同样三列（缩小内边距与字号），米黄纸底 + 轻微旋转 + 一枚图钉：
  - `现在`：在做什么（一句话）
  - `在听`：一首歌 / 一张专辑
  - `甜食`：最想吃的那一样
- 社交链接不放在这里，统一放页脚，避免重复。

**滚动动效**：进入视口时，图片先出现（translateY 20px → 0，600ms），文字三段依次淡入（间隔 90ms）。只播一次。

### 4.3 玄关 页脚（`#bye`）

- 大字号一句：`灯给你留着，晚安。`（32–40px，标题字体）。
- 一行品牌链接：Bilibili、小红书，使用各自 wordmark 图标；hover 抬升 3px + 暖色投影，新标签页打开并带 `noopener noreferrer`。
- 右下角「回到门口 ↑」按钮：滚回顶部，作为离站前的小小告别。
- 版权行：`© 2026 Gardenia · 用一晚上的灯做的`。
- 顶部 1px 分隔线，颜色 `#F6E7D3` 8% 透明。

### 4.4 全站微交互

| 交互 | 规格 | 降级 |
| --- | --- | --- |
| 光标暖光斑 | 640px 径向光，`mix-blend-mode: screen`，跟随鼠标 lerp 0.12 | 触屏 / `reduced-motion` 关闭 |
| 柔光游动 | 3 个光斑 26–32s 平移 + 缩放，只改 `transform` | 停在原位 |
| 火星粒子 | canvas 30–60 颗上升光尘，`lighter` 混合，单 rAF 驱动 | 隐藏画布 |
| 星点闪烁 | 移动端 32 / 桌面 48 颗 2px 红白黄星点，客户端随机铺满首屏并叠在照片上，1.5–3.5s 闪烁，指针视差约 18px | 静态、压暗 |
| 指针视差 | 光斑 22px / 照片 8px / 星点 18px，无指针时正弦漂移 | 触屏 / `reduced-motion` 关闭 |
| 滚动淡入 | IntersectionObserver，threshold 0.12，700ms，只播一次 | 直接显示 |
| 链接 hover | 0.35s 颜色过渡 + 细暖线展开 | 只变颜色 |
| 页面切换 | 无（单页） | — |
| 音效 | 本期不做，不自动播放任何音频 | — |

## 5. 视觉规范

### 5.1 色彩 Tokens

| Token | 值 | 用途 |
| --- | --- | --- |
| `--night-900` | `#090706` | 最深的页脚 / 暗角 |
| `--night-800` | `#100D0B` | 页面主底色（暖黑） |
| `--night-700` | `#18130F` | 卡片底 / 导航背板 |
| `--night-600` | `#241B15` | 分隔、悬浮底 |
| `--amber` | `#FFB24A` | 主光、强调、链接 hover |
| `--amber-soft` | `#FFE9C4` | 灯芯、标题微光 |
| `--ember` | `#E2683C` | 橙红点缀、印章、按钮 |
| `--ember-deep` | `#A8442A` | 暗部暖色、按钮按下 |
| `--cream` | `#F6E7D3` | 主文字 |
| `--cream-dim` | `#C9AE95` | 次要文字 |
| `--wood` | `#6B3F26` | 木纹、拍立得阴影 |
| `--paper` | `#F4E9D8` | 拍立得纸框、便签 |
| `--paper-ink` | `#4A3428` | 便签上的字 |

规则：同一屏内暖色面积不超过 30%；纯白 `#FFF` 只用于 1px 高光，不作为文字色（避免刺眼）。

### 5.2 字体

| 层级 | 字体 | 字号 / 行高 | 备注 |
| --- | --- | --- | --- |
| 展示标题 | LXGW WenKai（霞鹜文楷）500 | clamp(42px, 6.2vw, 86px) / 1.24；移动端 clamp(38px, 11.4vw, 54px) / 1.32 | 楷体带手写温度；自托管 `@fontsource/lxgw-wenkai` |
| 小标题 | 同上 | clamp(28px, 3.4vw, 40px) / 1.5 | 「关于我」标题，字距 0.03em |
| 正文 | Noto Sans SC Variable | 16–17px / 2.0 | 自托管 `@fontsource-variable/noto-sans-sc` |
| 眉标 / 标签 | 正文 | 11–12px / 1.6 | 字距 0.34em，全大写拉丁 |
| 手写体（签名、caption） | LXGW WenKai | 12–19px | 仅短句，避免长段落 |

兜底：`"LXGW WenKai", "Kaiti SC", "STKaiti", "KaiTi", "Noto Serif SC", serif`。字体加载失败不影响可读性，不用 `font-display: block`。

> 实现记录：最初选用 ZCOOL XiaoWei，实测该字体包中「回」渲染为实心方块，改为霞鹜文楷。

### 5.3 空间与形状

- 间距基数 8px；区块纵向内边距：桌面 120–160px，移动 72–88px。
- 内容最大宽 1080px，文本行宽 34–42 个汉字。
- 圆角：卡片 14px，拍立得 4px，按钮 999px，便签 6px。
- 阴影一律暖色，不用纯黑：
  - 近：`0 12px 30px rgba(40, 16, 8, 0.45)`
  - 远：`0 30px 80px rgba(30, 10, 4, 0.55)`
- 边框用 `rgba(246, 231, 211, 0.10)`，不用实色。

### 5.4 材质与光

1. **柔光斑**：三层大尺寸 radial-gradient（琥珀 `#FFB24A`、橙红 `#E2683C`、暗玫瑰 `#8A4A56`），`blur(40px)`，只动 `transform` 缓慢游走。
2. **星点**：2–3px 圆点 + 6px 光晕，分红 `#FF7A63` / 白 `#FFF6E8` / 黄 `#FFD166` 三色，`twinkle` 3–6 秒呼吸。
3. **火星**：canvas 预渲染 32px 径向光斑精灵，`globalCompositeOperation: 'lighter'` 叠加，暖橙 / 浅金 / 少量玫红。
4. **颗粒**：全站固定 SVG 噪点，`opacity: 0.045`，`mix-blend-mode: overlay`。
5. **暗角**：`radial-gradient(ellipse at 50% 42%, transparent 46%, rgba(0,0,0,.42) 100%)`。
6. **木纹**：仅首屏底部，来自图 1，横向拉伸、降低对比，叠一层暖色遮罩。
7. **图片统一调色**：`filter: sepia(0.14) saturate(0.95) brightness(0.8) contrast(1.04)`；拍立得内部再加一层暖色叠层（`mix-blend-mode: soft-light`, 12%）。

### 5.5 图标与装饰

- 只用线性图标，1.5px 描边，颜色继承文字。
- 装饰元素：胶带、图钉、印章、光尘。全部用 CSS / 内联 SVG，不引入图标库。
- 不使用 emoji 作为界面元素（正文里可以有，但按钮和标题不用）。

## 6. 技术方案

### 6.1 选型

| 项 | 选择 | 理由 |
| --- | --- | --- |
| 框架 | Astro 7 | 输出纯静态 HTML，首屏无 JS 框架负担；组件化写页面 |
| 交互 | `@astrojs/react` + React 19 | 只有光标光斑一个岛需要 JS，其余用 CSS / 原生脚本 |
| 语言 | TypeScript（strict） | 组件属性与数据结构有类型 |
| 样式 | 原生 CSS + CSS 变量 | 氛围需要精细控制，避免原子类淹没光影层次 |
| 字体 | `@fontsource` 自托管 | 不依赖外网 CDN，国内访问稳定 |
| 图片 | `astro:assets` | 自动 WebP/AVIF、尺寸与懒加载 |
| 包管理 | pnpm | 用户指定 |
| 动画库 | 不引入 | CSS keyframes + rAF + IntersectionObserver 足够 |

### 6.2 关键依赖

```bash
pnpm add astro @astrojs/react react react-dom
pnpm add -D typescript @types/react @types/react-dom
pnpm add @fontsource/lxgw-wenkai @fontsource-variable/noto-sans-sc
```

实测版本：Astro 7.4.5、`@astrojs/react` 7.1.2、React 19.3.1、TypeScript 7.0.2。

### 6.5 实现要点

- 图片从 `images/` **复制**到 `src/assets/photos/`，原图保留；构建时由 `astro:assets` 处理。
- 首屏背景图用 `<Image>` 并 `loading="eager"`、`fetchpriority="high"`；其余图片 `loading="lazy"`、`decoding="async"`。
- `CursorGlow` 用 `requestAnimationFrame` 做插值，监听 `pointermove`；`(pointer: coarse)` 或 `prefers-reduced-motion: reduce` 时不挂载逻辑。
- 首屏火星与指针视差共用一个原生 `requestAnimationFrame` 循环：canvas 按 DPR（上限 2）缩放，粒子数随面积取 14–64，`IntersectionObserver` 在首屏离开视口时暂停绘制。
- 视差只写 CSS 变量 `--px / --py`；无指针时用正弦缓慢漂移，触屏不启用。
- 星星由客户端 `Math.random()` 生成（移动端 32 / 桌面 48），位置与闪烁相位每次刷新都不同；样式用 `.hero__stars :global(.star)` 作用到 JS 创建的节点上；纯装饰层，禁用 JS 时为空，不影响正文与照片。
- 「回到门口」按钮与导航用原生脚本实现，避免为它们单独拉 React 岛。
- 噪点用一张 `public/noise.svg`（feTurbulence），避免生成图片。
- 所有动效写在 `@media (prefers-reduced-motion: no-preference)` 内或提供关闭分支。
- 滚动淡入默认可见；只有 JS 可用时（`html.has-js`）才隐藏等待出现，禁用 JS 也读得到全部内容。
- 布局给装饰光晕加 `overflow: hidden`，防止移动端被撑宽、触发浏览器缩放。
- 不写任何服务端代码，`output: 'static'`；也不加分析脚本、cookie、第三方追踪。

## 8. 非功能要求

### 8.1 性能

- 首屏 LCP < 2.5s（本地与 4G 模拟）。
- CLS < 0.05：所有图片有明确宽高比，字体 `font-display: swap` 且度量接近兜底。
- 首屏 JS（gzip 后）< 60KB：只有 CursorGlow 一个岛。
- 图片总传输 < 1.2MB（首屏），其余懒加载。
- 不使用网络字体以外的第三方请求。

### 8.2 可访问性

- 正文对比度 ≥ 4.5:1；次要文字 ≥ 3:1（`--cream-dim` 在 `--night-800` 上约 7:1，安全）。
- 所有交互元素可 Tab 到达，`focus-visible` 为 2px `--amber` 外环，偏移 3px。
- 「回到门口」按钮为原生 `button`，可键盘触发。
- 动效全部尊重 `prefers-reduced-motion`；关闭后不影响信息获取。
- 图片有中文 `alt`；纯装饰图 `alt=""`。
- 语义结构：`header / nav / main / section / footer`，一个 `h1`。

### 8.3 兼容

- 最近两个版本的 Chrome / Edge / Safari / Firefox；iOS Safari 16+。
- 降级策略：不支持 `backdrop-filter` 时用纯色半透明背板；不支持 `mask-image` 时木纹直接渐隐到透明（用叠层遮罩兜底）。

### 8.4 隐私

- 无统计、无埋点、无 cookie、无外部字体/图片请求。
- `localStorage` 只存灯的状态一个键。
